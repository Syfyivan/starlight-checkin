## 2. 现在宠物实际上做到了什么

### 经验、等级与外形

- 初次宠物由抽奖获得 `pet_companion` 卡，使用后入住；再次抽到同类卡，使用后增加 60 经验。
- 现有素材是 **糯糯海豹**，不是海豚；另有兜兜鼯鼠和棉桃寄居蟹。后两种是等级开放的可切换外形，不是海豹进化成其他物种。
- 每个领奖空间一只宠物。等级使用现有经验计算；没有蛋、孵化、进阶或重生状态机。
- 经验 = 净完成任务分数 + 有效的学习币全勤奖励 + 已使用用品的经验 + 已归来旅行的经验。消费学习币不扣经验。
- 撤销任务或调低任务分数可以降低经验、等级。装扮和形象会暂时重新锁定，但所有权保留。
- 当前有两种绘画姿态：Lv.1–3 为 `young`，Lv.4 起为 `winged`。`winged` 是旧素材文件名，不代表已经有灵兽进化。
- 现有贴合装扮的画面使用静态 PNG 加 SVG 配饰，让整体轻微呼吸；没有连续生长、破壳或换骨动画。目录里的 APNG 文件存在，不代表这些动画已接入当前装扮渲染。

### 旅行现状

1. 商城买口粮/旅行用品，进入「成长记录 → 准备行囊」。每趟 1–2 件，最多一份食物、一件用品，不能把装扮当行囊。
2. 出发时消耗卡片并保存目的地、时长、礼物、形象快照。刷新或重试不会重抽结果。
3. 半天/一天/两天/三天的概率分别为 50%/30%/15%/5%。旅途中不能喂食或换装。
4. 归来后增加行囊经验、发一封信；70% 只带见闻，20% 加一次抽奖机会，8% 加口粮，2% 加蝴蝶结。重复装扮换口粮。
5. 礼物在信箱单次领取。离线到期由服务维护或状态刷新处理；故事是有知识来源的虚构旅行，地图不表示真实定位。

行囊只影响经验，不影响时长或中奖率。已有最近六封明信片、旅行邀请、事务和防重复处理。没有真实地点探索、路线选择、目的地收藏或新的进化旅行。

## 3. 下一版进化设计草案（尚未实现）

用户想看到：小小的蛋慢慢成为伙伴，长大后可以进入更漂亮的灵兽阶段；每一步有精致的新形象。推荐先做好**一条海豹成长线**，再扩其他物种。若最终要海豚，应制作完整的海豚素材，不能只改海豹名称。

```text
云朵蛋 → 糯糯幼崽 → 元气伙伴 → 星辉灵蛋 → 月光幼灵 → 星海伙伴
 首次孵化              自愿进阶       再次孵化
```

这是奇幻伙伴的成长设定，不把海豹描述成现实中卵生的动物。名字、门槛和以下交互均为建议值，需在本地演示中评估后定稿。

| 阶段 | 建议资格 | 操作与展示 |
| --- | --- | --- |
| 云朵蛋 | 新玩家抽到并使用首次伙伴卡 | 简短破壳互动即可孵化；不再收一次钱、不再赌一次概率 |
| 糯糯幼崽 | 初次孵化 | 小巧、柔软的第一阶段 |
| 元气伙伴 | Lv.4 / 600 经验 | 达标提示「长大一点啦」，由用户确认展示；独立绘画，不是放大图片 |
| 星辉灵蛋 | Lv.7 / 2400 经验，且不在旅行 | 用户主动选择进阶；先说明形象会暂时成为灵蛋，等级、财产和衣橱不清零 |
| 月光幼灵 | Lv.8 / 3400 经验，已进入灵蛋阶段 | 可以孵化进阶伙伴；用户可稍后操作 |
| 星海伙伴 | Lv.10 / 6000 经验 | 更精细的最终外形；第一版到此为止，不做无限重生 |

### 等级与进化要分清

- **等级资格**继续由现有经验决定，用于用品解锁；**进化阶段**是用户已经完成的成长动作，应持久化，不能只靠前端经验临时推算。
- 学习币仍是可消费资产，经验仍按现有规则累计；不要为了进化默默改币值、扣经验或重发经验奖励。
- 长期任务已经允许领奖人填写 1–1,000,000 学习币，发奖人可以调整；它不受普通任务的每日发币上限限制（`lib/task-plans.mjs` 的 `award`）。一个高分任务可能直接达到 Lv.10；这与“缓慢养成”有冲突。
- 第一版建议先保留已承诺的分数与经验规则：高经验可以获得后续资格，但每个阶段仍由用户依次确认，不自动跳过动画或强制变蛋。这**不能保证慢速养成**。
- 如果必须让高经验用户也经历数天陪伴，需要另定最短陪伴天数或养成条件。此项尚未确认，不偷偷增加每日签到要求，也不先改长期任务奖励。
- 经验回退不能让已经孵化的伙伴反复变蛋、重复领奖。建议保留已完成进化外观，用品购买/使用仍按当前等级校验；这与现有“形象随等级回退”的机制不同，实施前要明确兼容规则。

### 旧数据、旅行和衣橱

- 旧宠物直接保留当前外形、经验和装扮，不强制回到蛋、不补发币或经验。旧存档怎样映射到成长阶段需单独迁移测试。
- 兜兜鼯鼠、棉桃寄居蟹作为已开放外形保留，第一版不冒充进化节点；其他物种成长素材未完成前，不开放其进阶按钮。
- 正在旅行时不能进阶/孵化；归来故事使用出发时快照。刷新、重复点击、断网重试、重启不能造成双重孵化或消耗。
- 蛋阶段可以暂不显示装扮，但保留拥有权和之前搭配；孵化后恢复可用装扮。未适配新身体的装扮需提示暂不可穿，不能出现悬空或穿进脸里。
- 新增持久化阶段与一次性事件时，沿用现有迁移、事务、操作日志、幂等模式。不要覆写 `young/winged` 的历史含义导致旧行程快照失效。
- 「小衣橱」只展示下一档解锁条件，不铺满十级说明；详细规则折叠。孵化与升级动画可跳过，支持减少动态效果。

### 美术交付门槛

每个阶段需有统一画幅、基准点、透明背景、落脚位置、配饰锚点和前后遮挡关系。最小动作建议：待机/眨眼、开心、进食、睡觉；蛋另需轻晃和破壳，进阶另需转换过渡。每种状态都要有静态降级图。

先完成同一条物种线的模型和一组配饰适配，再扩数量。不要用简单缩放、全身滤镜或未经适配的通用帽子充当新阶段。素材没做好时保持 `ready:false`，只显示灰色轮廓，真实名称和图像不能从提示框提前露出。

现有角色来自用户授权复用的 Kodama 项目，见 [素材说明](../public/pets/ASSET-SOURCE.md)。公共仓库不等于这些角色允许任意再分发；新素材同样记录来源和使用权。当前无需新增渲染框架或依赖。
