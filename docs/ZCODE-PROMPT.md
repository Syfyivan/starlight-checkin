## 我的目标

1. 装扮按经验逐渐开放，起初少一些，以后越来越多。未解锁的形象、食物和装扮只能显示灰色轮廓，不能透出真实图案/名字；尚未做好的不能买。
2. 宠物要有完整成长过程：蛋 → 幼崽 → 长大 → 高阶灵蛋 → 再孵化 → 更可爱精致的伙伴。当前代码只有等级与三种可切换外形，没有这条进化链，不要混淆。
3. 我说过“小海豚”，但现有素材实际是糯糯海豹。先用现有素材验收；制作进化线之前说明物种和方案，别简单改个名字。
4. 装扮需要贴合不同身体和动作，不能悬空、挡脸、穿模。手机界面要精致、紧凑，任务仍是首页重点，文案可爱但少说废话。
5. 学习币是资产，经验用于成长。长期任务可以由领奖人设置很高的分数，1000 只是示例，不能改成上限。高分任务可能快速满级，进化节奏需要明确设计，不能暗中减少任务币或经验。

## 第二阶段：接手进化与体验完善

`docs/ZCODE-HANDOFF.md` 第 3、4 节包含设计草案和缺口。阶段名、Lv.4/7/8/10 进化资格、是否加陪伴天数、旧宠物映射规则都是待定方案，不是已经上线的要求。先给我一份简短的推荐与本地视觉预览，集中确认这些会影响现有体验的选择；不需要为已明确的普通修复反复问许可。

确定后先做一条物种的完整成长线：
